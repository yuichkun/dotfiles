# Image attachments

Pi のクリップボード画像を入力欄の文字列ではなく、入力欄の上にある attachment bar として扱う extension。

## 操作

- `Ctrl+V`: 画像を添付。テキストのクリップボードは通常どおり入力欄へ貼り付ける
- `↑`: 入力カーソルが最上段にある場合、最後に添付した画像へフォーカス
- `←` / `→`: フォーカスする画像を移動
- `Backspace`: フォーカスしている画像を削除
- `↓` / `Esc`: 添付バーから入力欄へ戻る
- `Enter`: 入力文と画像を送信。画像だけでも送信可能

入力カーソルが最上段以外にある場合、`↑` は通常のカーソル移動として動作する。補完候補を表示している間も、`↑` は候補選択を優先する。

画像はモデルへ送信する前に Pi の標準画像処理でリサイズされる。一時ファイルのパスは入力文に含めず、`input` event の画像データとして送信する。

## macOS / iTerm2

Pi が直接認識できるのは `Ctrl+V`。`Cmd+V` は通常 iTerm2 が OS の「Paste」として先に処理する。
iTerm2 の profile key mapping で `Cmd+V` を `Send Hex Code: 0x16` にすれば Pi へ `Ctrl+V` として転送できるが、その profile の通常 shell でも `Cmd+V` が OS paste ではなくなる。Pi 専用 profile での利用を推奨する。
