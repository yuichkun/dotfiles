# フィードバック質問セット（固定）— 提示と回答の受け方

鑑賞が終わったら、以下の質問を**一言一句このまま**提示する。試行間の比較可能性を保つため、言い換え・省略・順序変更をしない。パーソナライズした例示や回答支援は、原文を提示した後にだけ行う。

回答は `assets/feedback-template.md` の形式でまとめる。

## 提示の仕方

- **一問ずつ**出す。7問を一括で並べない
- 各質問に `質問 1/7` の形式で現在地を付け、残りの設問数が分かるようにする
- 質問UIツールが使える環境ではそれを優先し、無ければ通常メッセージで同じ進行を守る
- 本人が「まとめて答えたい」と言った場合はそれに従う

## 回答の受け方

伴走で得た文脈は、質問するためだけでなく、本人が答えやすい状態を作るために使う:

- 次の質問へ進む前に、設問が要求する要素（数値・理由・具体箇所）が揃っているか確認する
- 不足があっても自由記述を再要求しない。伴走で得た文脈から2〜3個の解釈候補を出し、最有力を仮置きして「この理解で合っているか」を短く確認する
- 評価尺度（質問1）では、本人が実際に遭遇し得る相手・用途・判断場面を例示し、まず数値や短い反応だけ受け取る。理由の言語化はAIが下書きし、本人には確認だけ求める
- 記憶や発見を尋ねる設問（質問3）では、調査中に見つけた本人固有の候補を3〜4件示し、全経歴を思い返させない
- 本人に作文・修正を投げ返さない。文面はAIが書き切り、違うと言われたら修正候補もこちらから出す
- 走行内容に応じた補足の深掘りは最大2問まで。`補足 1/2` のように残数を付ける
- 本人の発言にない理由・評価を確定しない。集約前に、要約が本人の意図と合うか確認する
- 本人が「この設問は支援不要」と言ったら、回答を原文のまま採用し、解釈・言い換え・確認質問を追加しない

### 質問6の扱い

質問6はオープンクエスチョンのまま受ける。このスキルを走らせるエージェントには LAPRAS のサービスドメイン知識がないため、推測に基づく選択肢・機能案・UI軸で回答を具体化しない。回答が提供形態を一つ示していれば、その表現をそのまま記録して次へ進む。

---

## 質問（このまま提示する）

1. **このポートフォリオを、人に見せたいと思えますか？** 5段階（1=見せたくない 〜 5=今すぐ見せたい）と、その理由を教えてください。

2. **「AIっぽさ」を感じた箇所はありましたか？** あれば、どこで・どう感じたかを具体的に。なければ「なし」で構いません。

3. **自分でも気づいていなかった発見はありましたか？** 「こんな事実が拾われていた」「この切り口は考えたことがなかった」など、どの事実・どの構成かを具体的に。

4. **事実の誤りや、画像・実績の誤った紐づけを見つけましたか？** 見つけた場合は、件数と内容を教えてください（これは重要な計測項目なので、遠慮なく全部挙げてください）。

5. **「LAPRAS上のデータだけでは作れなかった」と感じる部分はどこですか？** 記事の本文、リポジトリの中身、取材記事など、外部情報が効いていると感じた箇所を教えてください。

6. **この体験を今後ユーザーへ提供するとしたら、どのような形がよいと思いますか？** 今回のようなスキル配布のまま・LAPRASのサービス内で・それ以外の形、なんでも構いません。開始のしかた・伴走のしかた・更新のしかた・成果物の受け取り方など、自由に書いてください。

7. **プロセスはどうでしたか？** 方向性を選ぶところ、途中の確認、質問のされ方などで、良かった点・邪魔だった点があれば教えてください。

## 離脱時

途中でやめる場合（時間切れ・飽きた・つまずいた等、理由は何でも）も、次の一行だけ esa にコメントしてもらうよう案内する:

> どのフェーズで・なぜやめたか（例:「調査の途中。時間がかかりすぎた」「方向性提案がピンとこなかった」）

完走データより離脱データの方が貴重なので、気軽に書いてもらう。
