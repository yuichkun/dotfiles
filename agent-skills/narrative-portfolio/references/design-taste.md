# デザインの規律 — slop回避と方向性提案の作り方

## AI slop の正体は「決断の不在」

個々の要素が悪いのではなく、どこにも人間（あるいは作り手）の判断の痕跡がない状態が slop シグナルになる。避けるべき定番:

- 紫→青のグラデーション、ぼかしグラデ玉 + ガラス風カード
- どの要素も同じ角丸・同じ padding・同じ薄い影。全部中央揃え・全部対称
- 階層のジャンプが弱いタイポグラフィ（1.5倍刻み）。craft は3倍以上の大胆なジャンプ
- 全要素に同じ fade-in-up、意味のない装飾モーション
- 未加工のAI生成イラストをヒーローに置く
- 絵文字アイコン、無重力なコピー（「もっと速く、もっと賢く」型）

## 効く原則

- **1つの支配的メタファーに全コミット**する（記録簿をめくる／計器を読む／地図を歩く、など — メタファーは対象者の生活と道具から選ぶ）
- **実在の記録が最強の素材**。実物のスクリーンショット・実測の数字・原文の引用が生む説得力は、テンプレートやAI生成画像では偽造できない。抽象的なデータ可視化（波形・星図）より「実在の仕事の物理的な記録・アーカイブ」系の方が本人に選ばれやすい
- **色の規律**: 支配色1 + アクセント1 + 規律あるニュートラル。素材からパレットを引く
- **タイポグラフィがアイデンティティ**。少数のファミリー、極端なスケールコントラスト、数字を図形として扱う
- **テクスチャは実在の物質から**（紙・フィルムグレイン・網点・ピクセル）
- **余白と間もコンテンツ**。詰めて埋めない
- 日本語の縦書き・明朝は強い道具になるが、行長・行間・フォントフォールバックに注意する

## 方向性提案の作り方（Phase 2）

1. 調査書から、その人の「人物性の軸」を言語化する（例: 音楽×コード、研究×現場、長期の一貫性、越境癖）
2. 表現の系統を複数軸で発想する。参考の軸: 印刷物系（台帳・年報・図鑑）／映像系（フィルム・スライド）／計器・ログ系（記録計・コミットログ）／空間系（地図・博物館）／遊戯系（ゲーム・カード）。**ただし軸自体をその人の人物性から発想し直すこと**。過去事例の完成形を候補として持ち込まない
3. 各軸に1〜数案の「雰囲気見本」を静的HTMLで作る。目安は3〜5系統×各2〜4案（素材の厚さや本人の時間に応じて減らしてよい。守るべきは案の数ではなく**複数軸×複数案**という構造）。1案 = 1画面、色・書体・質感・タイトルの入り方が伝わる最小限。**捨てられる粒度**を守る（ここで作り込むのは判断機会の横取り）
   - 見本に置く事実（年号・数字・引用）も**調査書にあるものだけ**。演出のために年号や数字を創作しない。不明なら置かない — 見本段階の創作が最終作品に紛れ込むのが捏造の入口になる
4. 選抜ボード（全案を並べて見られる1ページ）を作って本人に渡し、一緒に絞る
5. 落選案から得た「刺さらない傾向」も記録しておく。以降の判断材料になる

## 実装の規律（Phase 5）

- 依存ゼロの静的ファイル。ビルド不要、CDN読み込みなし、相対パス
- モーションは抑制的に。入場は ease-out、hover は 150–200ms、同時に動く焦点は1つ
- 音声は既定で入れない（本人が積極的に望み、素材を持っている場合のみ）
- レイアウトは可変コンテンツに耐える構造にする。固定幅の箱に可変長テキストを流し込むと、環境差で必ず壊れる。自動幅・min-width の解除・overflow時の挙動を設計する
- 日本語タイポグラフィの具体則:
  - **日本語をイタリックにしない**（強調はウェイトか「」で）
  - 本文の行間は 1.7 前後（欧文の 1.5 より広め）
  - 書体は**システムフォントスタック**で指定し、Webフォントの外部読み込みはしない（依存ゼロ原則）。例: 明朝 `"Hiragino Mincho ProN", "Yu Mincho", serif` / ゴシック `"Hiragino Kaku Gothic ProN", "Yu Gothic", sans-serif`
  - 見出しなど大きいサイズでは `font-feature-settings: "palt"` で詰めが効く
